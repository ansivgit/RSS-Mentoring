# RSS-Mentoring

Settings, examples, and snippets for mentoring students at Rolling Scopes School. This setting use eslint v.9+

## Getting Started

`npm install react react-dom`

`npm install -D eslint@9.39.4 @eslint/js@9.39.4`

`npm install -D eslint-plugin-unicorn typescript typescript-eslint vite eslint-plugin-react eslint-plugin-react-hooks eslint-plugin-react-refresh eslint-plugin-unicorn globals @types/node @types/react @types/react-dom @vitejs/plugin-react prettier eslint-plugin-prettier eslint-config-prettier stylelint stylelint-config-clean-order stylelint-config-standard stylelint-order stylelint-prettier`
